**Flags on P** (for the orchestrator):
1. **One set carries it.** dev is flat (+0.001: ig +0.017, yt −0.014) and `known_dev` loses a little.
   - `ig_known_dev` is synthetic, and every target is on Instagram. Any shift toward Instagram that the library terms back helps there.
   - `known_dev` is the opposite case (all YouTube), and there P loses −0.004. So the gain is not a plain Instagram tilt, but the two single-platform sets reward a confident platform read far more than mixed searches would.
2. **It is fragile.** mrr2 CI > 0 disappears without the best `ig_known_dev` search, Holm fails on mrr2, and per repeat the gain runs +0.018 to +0.043. The non-inferiority point clause on `known_dev` holds by 0.0008, and that CI excludes 0 (a small loss, below its MDE).
3. **Misreads are rarer but still costly** (section 3). Dev MRR falls −0.022 (descriptive), and dev's YouTube scope is −0.014. No `both`-scope search exists to test mixed intent.
4. **Grades are not an issue.** P's dev result is unchanged across every label variant (seed +0.001, grade-1 → 0 +0.001), and the known sets are not pooled.

**Note on F:** F is the only arm with a dev gain that holds up across grades. It is all YouTube (+0.081 [+0.028, +0.147], 12/4) and mostly name / structure / said-shown searches; Instagram scope is 0. It loses on the Instagram known-item set. A YouTube-scope or long-query refine is a plausible follow-up, but it needs a fresh test, not a reading of this one.
