## Arm definitions (as preregistered)

**q_ig in both arms** is P's platform read exactly as in TI: prior-p1, computed from the own-list fusion (without te lists), unrounded. It is therefore the same number in P, TI, FY, TG and TFY for a given search and repeat.

**Y8.4-TG · `tg-v1`.**
- With q_ig ≥ 0.5, a typed search is exactly TI: te-v1c Instagram-only lists in the coverage-fair group, then P's multiplier.
- With q_ig < 0.5, it is exactly P: no te lists.
- This applies on both paths. No soft form was run.

**Y8.4-TFY · `tfy-v1`.**
- Every typed search starts as TI.
- On rewrite-routed searches with q_ig < 0.5 (strict), round 8.3's FY refine runs on TI's weighted top 20, in TI's order. The refine is rf-v1 unchanged: gpt-5-nano, minimal reasoning, strict id schema, friend rule, reorder rule.
- A cached response is reused only when the inputs are identical: same repeat, same search, same candidate ids in the same order.

6. **The `ig_known_dev` bias flag from round 8.3 carries over.** TG removes te lists from P's YouTube reads there, and those searches are all P misreads.
7. **Process:** the seed re-runs ran in the background across a worker pause. On resumption all 12 seed files were present and complete, the comparisons had printed 586 / 586 for every file, and the ledger showed no new calls. Nothing was re-run or re-paid.
