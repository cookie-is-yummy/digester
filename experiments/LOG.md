# Experiment log

One row per experiment. The experimenter fills in the first columns **before** running; the evaluator fills in the result. Negative results stay. Scores are dev nDCG@10 unless stated.

## Protocol notes

- **Label rounds.** r0 = labels as handed over. r1 = +31 pooled judgments of the baseline's unjudged dev top 10 (11 graded 2, 9 graded 1, 11 graded 0), evaluator round 1. r2 = +127 pooled judgments of experiment 1's runs (3 graded 2, 32 graded 1, 92 graded 0), evaluator round 2. Every result names its label round; comparisons use the same round.
- **MU presence leaks labels.** Muse described 5% of the corpus but 95% of the labelled answers. Moving MU items first, with no MU text, gives +0.156 (see `results/muse-ceiling.md`). Any method that happens to favour "the kind of items Muse described" looks better than it is; pooled judging of new top-10 items is the correction, so evaluators pool whenever `unjudged10` > 0.15.
- **Rule notes.** (1) Evaluator round 1 read MU text for the inventory before blind-judging the r1 pool: a small contamination risk; later judging rounds use evaluators that have not read MU. (2) For more-like-this lines the judging sheet has no query text, so the r1 judge judged against the example items listed in `queries.jsonl`. (3) One Gemini diagnostic call bypassed `lib/ai.py` (logged by hand; see STATE.md).
- **Honest base from experiment 1 on:** the real gpt-5-nano rewrite (qr-v1). Its three repeats differ a lot per search (mean per-search range 0.13), so later experiments run on all three cached rewrite sets and report the mean paired Δ against the same-repeat base.
- **Test-split scorings used: 1 of 3** (the phase-1 "all 22" reproduction).
